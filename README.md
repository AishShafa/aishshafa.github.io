# Portfolio

My portfolio website. The portfolio highlights professional experience, selected projects, education, technical tools, and ways to get in touch. It is designed as a polished, responsive single-page experience with an interactive visual presentation.

You can visit the live website at [aishshafa.github.io](https://aishshafa.github.io)

## Overview

The site includes:

- A personal introduction and professional profile
- Selected recent projects
- Education and background information
- An overview of technical tools and technologies
- GitHub and LinkedIn profile links
- Direct email contact
- Responsive navigation between portfolio sections
- Interactive visual effects, including an animated gradient background and spotlight card interactions

## Built With

- [React](https://react.dev/) — Component-based user interface development
- [Quickly](https://vite.dev/) — Development server and production build tooling
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first styling
- [shadcn](https://ui.shadcn.com/) — UI development utilities and components
- JavaScript, HTML, and CSS

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

Clone the repository and install the project dependencies:

```bash
git clone https://github.com/AishShafa/aishshafa.github.io.git
cd aishshafa.github.io
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Vite will provide a local URL where you can preview the portfolio in your browser.

### Production Build

Create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

### Linting

Run ESLint to check the project for code-quality issues:

```bash
npm run lint
```

This project is configured as a Vite-powered frontend and can be deployed to any static hosting provider that supports single-page applications. It is also suitable for deployment through GitHub Pages or a similar static hosting platform.
